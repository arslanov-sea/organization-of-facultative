# Организация факультативов

Учебный проект по дисциплине "Проектирование информационных систем". Веб-приложение на Python (Flask) для управления данными студентов.

## Что делает

Приложение позволяет просматривать список студентов, добавлять новых, редактировать и удалять существующих. Поддерживается фильтрация по имени, телефону, адресу и количеству обязательных факультативных часов, а также сортировка по любому из этих полей.

Список студентов разбит на страницы. На стартовой странице можно выбрать университет — для каждого используется свой источник данных.

## Из чего состоит

Проект сделан с применением паттернов проектирования:

- Класс `Student` наследуется от `Person` и содержит валидацию всех полей: формат имени, адрес (должен содержать улицу и номер дома), телефон в формате `+7XXXXXXXXXX`.
- Репозиторий реализован в трёх вариантах: JSON, YAML и PostgreSQL. Все три работают через единый интерфейс.
- Паттерн **Адаптер** используется для подключения разных источников данных.
- Паттерн **Одиночка** применён к репозиторию.
- Паттерн **Декоратор** добавляет фильтрацию и сортировку поверх любого репозитория.
- Паттерн **Наблюдатель** связывает контроллер и представление.
- Паттерн **Фабрика** создаёт нужный репозиторий в зависимости от выбранного университета.

## Стек

## Запуск

1. Установить зависимости:
   ```
   pip install flask
   ```
   Если используется PostgreSQL, дополнительно:
   ```
   pip install psycopg2
   ```

2. Запустить приложение:
   ```
   python student_manager/app.py
   ```

3. Открыть в браузере `http://127.0.0.1:5000/`

На стартовой странице нужно выбрать университет, после чего откроется список студентов.
